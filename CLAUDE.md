# jha

Website for Jenny Hall Art (jennyhallart.com) — a portfolio site for Jenny's paintings and portraits.

## Vision

**Problem:** The current site is a dated Bootstrap 4 template-based design (built 2020) that's due for a refresh — both the visual design and how easy it is to keep up to date with new work.

**Goals / success criteria:**
- Modern visual redesign — move off the dated Bootstrap 4 look to fresher typography, layout, and color
- Better mobile experience
- Easier for Jenny to update herself — add/remove artwork or update content without needing hand-edited HTML each time
- Better gallery/portfolio presentation — improved image display, browsing/lightbox experience, and categorization

**Target users:** Jenny Hall (site owner/artist, primary content maintainer) and her site visitors/prospective clients.

**Non-goals:** No hosting or stack change — stays static HTML/CSS/JS deployed via GitHub Pages with the existing `jennyhallart.com` domain.

## Backlog

Work is tracked as GitHub issues using the User Story / Bug templates (see `andersonhall/ai-sdlc`'s `docs/conventions.md` for the format). The acceptance criteria checklist is the Definition of Done.

## Deployment

Static site served via GitHub Pages, with the custom domain `jennyhallart.com` configured through the `CNAME` file at the repo root.
